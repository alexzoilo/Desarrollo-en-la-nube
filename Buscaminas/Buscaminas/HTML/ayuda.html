Introducción

Bienvenido a la documentación del proyecto Buscaminas. Aquí aprenderás cómo funciona el juego y cómo está implementado.

Instalación

Para instalar el proyecto, simplemente clona el repositorio y abre el archivo index.html en tu navegador.

Reglas del Juego

El objetivo del Buscaminas es descubrir todas las casillas que no contienen minas sin detonarlas. Cada número indica la cantidad de minas adyacentes.

Interfaz

El juego consiste en un tablero de celdas. Puedes hacer clic izquierdo para descubrir una celda y clic derecho para marcar una mina.

Código

El proyecto utiliza HTML, CSS y JavaScript para la lógica del juego y la interacción con el usuario.
