Descripción del Proyecto

Proyecto Buscaminas en Java. El jugador debe descubrir todas las celdas seguras del tablero sin activar minas.

Funciones principales:

  • Crear un usuario.
  • Iniciar sesión.
  • Seleccionar dificultad.
  • Registrar estadísticas.
  • Reiniciar la partida en cualquier momento.

Requisitos Funcionales

  • Generar tablero con minas aleatorias según dificultad.
  • Descubrir celdas.
  • Mostrar número de minas adyacentes.
  • Indicar si el jugador ha tocado una mina o ha ganado.
  • Seleccionar dificultad (FÁCIL, MEDIO, DIFÍCIL).
  • Crear cuenta, iniciar/cerrar sesión.
  • Reiniciar juego y registrar partidas jugadas.
  • Mostrar estado de la partida y tiempo transcurrido.

Requisitos No Funcionales

  • Ejecutarse en cualquier entorno Java 8+.
  • Respuesta inmediata al descubrir celdas.
  • Código claro, modular y mantenible.
  • Manejo de entradas incorrectas.
  • Generación aleatoria fiable de minas.
  • Escalable a nuevos tamaños de tablero o dificultades.

Lógica Básica del Juego

  1. Inicia sesión o se registra el usuario.
  2. Selecciona dificultad.
  3. Se genera tablero con minas aleatorias.
  4. Descubre celdas:
    • Mina → pierde.
    • Descubre todas las seguras → gana.
  5. Puede reiniciar o salir.
  6. Se registran estadísticas y tiempo de partida.

Clases Principales

Usuario

  • Atributos: nombre, contraseña, partidasGanadas, partidasPerdidas, tiempoTotalJugado, tiempoUltimaPartida
  • Métodos: crearUsuario(), autenticar(), actualizarEstadisticas()

Buscaminas

  • Atributos: tablero, minas, filas, columnas, dificultad, jugador, tiempoInicio/fin
  • Métodos: iniciar(), mostrarTablero(), descubrir(), verificarVictoria(), reiniciar(), calcularPuntuacion(), iniciarCronometro(), detenerCronometro()

Dificultad (Enum)

  • FACIL, MEDIO, DIFÍCIL
  • Define filas, columnas y minas
